# LaunchBox

### The ultimate game library organizer and launcher

LaunchBox is a premium game library manager and beautiful frontend for emulators. Organize your entire gaming collection — from PC games to ROMs — with rich metadata, artwork, and a gorgeous Big Box mode for TV play.

<br>

---

## Features

| | |
|:---|:---|
| **Big Box Mode** | A stunning 10-foot UI for couch gaming with controller navigation |
| **Auto Metadata** | Automatically downloads box art, screenshots, and game descriptions |
| **Emulator Integration** | Works with RetroArch, Dolphin, PCSX2, and hundreds of emulators |
| **Platform Support** | Organize PC, console, arcade, handheld, and any other game system |
